# Codex Aura

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

まばたきと髪の揺れを添える、Codex 用のクリック透過アニメ調オーバーレイ。外観をリアルタイムで調整できます。macOS はソースからローカルビルド、Windows は x64 インストーラーで提供します。

独立した非公式のコンパニオンです。Codex 自体を変更せず、チャット内容も読み取りません。オリジナルのキャラクターテクスチャを共通の Canvas/WebGL で描画します。起動ごとに線画からカラーへのイントロを一度再生し、その後はまばたきと髪の動きを続けます。動作はアプリの前面状態に従い、モデルの処理状況や実際の読み込み進捗を示すものではありません。

## プラットフォームと配布方法

| 環境 | 配布方法 | 状態 |
| --- | --- | --- |
| macOS | ソースからローカルビルド・署名 | Apple Silicon で検証済み、Intel は未検証 |
| Windows 11 x64 | `CodexAura-1.5.0-windows-x64-setup.exe` | プレビュー版。[検証記録](docs/verification.md)参照 |

1.5.0 は即時の言語切り替えと 2 人のキャラクターを含みます。新しいプレビュー版は [Releases](https://github.com/pikad520/codex-aura/releases) から取得できます。

macOS の ZIP/DMG、Windows のポータブル ZIP、x86・ARM64 インストーラーは提供しません。両 OS のネイティブ UI、Windows インストーラー、ドキュメントは英語・簡体中国語・日本語に対応しています。

## macOS のローカルビルドと署名

Swift 5.7 以降を含む Xcode Command Line Tools をインストールし、自分の Mac でビルドします。

```sh
xcode-select --install  # 開発ツールが未導入の場合のみ。
git clone https://github.com/pikad520/codex-aura.git
cd codex-aura
./build.sh
codesign --verify --deep --strict 'Codex Aura.app'
open 'Codex Aura.app'
```

標準のビルドに**有料 Apple 開発者アカウント、Developer ID 証明書、署名用環境変数、API キーは不要**です。`build.sh` は `codesign --force --sign -` で **ad-hoc のローカル署名**を付けます。整合性の確認に使う署名であり、信頼された発行者の証明や Apple の公証ではありません。ローカルビルド向けの方法で、生成したアプリを再配布すると Gatekeeper の警告が出る場合があります。同梱ファイルを変更した場合は再ビルドしてください。配布用の署名は [Apple の説明](https://developer.apple.com/documentation/xcode/creating-distribution-signed-code-for-the-mac/)を参照してください。

現在の Mac のアーキテクチャ向けに、macOS 12.0 を最低デプロイ対象としてビルドします。実際のローカル検証環境は **macOS 26.5.1（25F80）、arm64、Swift 6.3.2**。対象アプリは **26.1007.30912（20156）**、バンドル ID は `com.openai.codex` です。別の ID は自動対応しません。最低デプロイ対象は、全 OS バージョンでの動作確認を意味しません。

生成したアプリを Applications にドラッグするか、Python 3 で `~/Applications/Codex Aura.app` にインストールします。

```sh
python3 manage.py install
# スクリプトでのインストール後、必要な場合のみログイン時起動を有効化：
python3 manage.py enable-login
```

Finder 用の `安装并启动.command` と `开启登录自启.command` は `/usr/bin/python3`、上記コマンドは PATH 上の `python3` を使用します。アプリの実行に Python は不要です。インストールでログイン時起動を新たに有効化せず、更新では明示的に有効にした設定を維持します。

## Windows x64 インストーラー

[Releases](https://github.com/pikad520/codex-aura/releases) から x64 Setup を取得します。開発ビルドは [GitHub Actions](https://github.com/pikad520/codex-aura/actions/workflows/verify.yml) のインストーラー成果物でも取得できます（ログインが必要な場合があります）。Actions のダウンロードにはインストーラーと SHA-256 チェックサムが含まれ、ポータブル版ではありません。

**Windows 11 x64**（ビルド 22000 以降）と [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) が必要です。Runtime がない場合、セットアップは Microsoft のダウンロードページを開くか確認します。Runtime をインストールしてからセットアップを再実行してください。無断でダウンロードは行いません。.NET ランタイムはアプリに含まれ、利用者に .NET SDK、Python、Node.js は不要です。

管理者権限なしで `%LOCALAPPDATA%\Programs\Codex Aura` にインストールします。ログイン時起動とデスクトップショートカットは任意で、初期状態では無効です。スタートメニューから起動し、Codex を開きます。現在は前面プロセス名 **`Codex.exe`** を大文字・小文字を区別せず照合し、ウィンドウタイトルは使用しません。別の実行ファイル名は自動対応しません。

インストーラーは現在**発行者署名なし**です。不明な発行者や SmartScreen の警告、システムポリシーによるブロックが発生する場合があります。入手元とチェックサムを確認してください。Windows 上の実際の Codex を使った一連の動作確認は未完了です。検証記録では専用テストウィンドウと実際のアプリ互換性を区別しています。

## 操作と動作

**macOS のフォルダー音楽：**背景のない透明な 2 段ツールバーが Codex タイトルバーの右側 3 分の 1 に追従し、キャラクターの下、Codex の上に重なります。上段はフォルダー、プレイリスト、ループ／ランダム、前の曲、再生／一時停止、次の曲、音量。下段は再生時間、シークバー、合計時間です。フォルダー直下の音声を自動再生し、サブフォルダーは含めません。ファイル名をラテン文字 A–Z、漢字のピンイン、仮名の五十音、その他の順に並べます。ループは全曲を巡回し、ランダムは他に再生できる曲があれば同じ曲を続けません。前の曲は実際の再生履歴を戻ります。リストは 5 行を表示し、最後までスクロールして 1 回のクリックで切り替えられます。空のフォルダーや読み込み失敗では元の再生を維持します。初期音量は 50% で、スピーカーボタンでミュート／解除できます。髪の保護領域と滑らかな音楽連動は維持します。切り替え・非表示中も再生し、終了で停止。「視差効果を減らす」設定ではキャラクターは静止します。フォルダーと位置は保存せず、Windows は未対応です。狭いウィンドウではタイトルバーの下に配置します。太陽メニューで音楽コントロールの表示／非表示とクリックの波紋を切り替えられます。コントロールを隠しても音楽と髪の反応は続きます。切り替えは今回の起動中に適用されます。前面の Codex 内を左クリックすると淡い青色の輪が短く広がり、元のクリックは変更しません。「視差効果を減らす」設定では波紋も停止します。

macOS のメニューバー、または Windows の通知領域の太陽アイコンから **调色控制面板… / Appearance…** を選びます。スライダーと数値入力は即時反映・自動保存されます。macOS では初回起動時にパネルが表示され、Windows ではトレイメニューまたはアイコンのダブルクリックで開きます。

**言語**欄では **システムに従う / English / 简体中文 / 日本語** を選べます。新規インストールや言語設定のない旧バージョンでは OS の優先 UI 言語を使用します。中国語系は簡体中国語、日本語は日本語、それ以外の未対応言語は英語になります。手動選択はパネルとメニューに即座に反映され、自動保存されます。「システムに従う」に戻すと自動選択になり、OS の言語変更は次回起動時に読み取ります。言語の切り替えや初期値へのリセットで、キャラクターやイントロの進行は変わりません。数値書式はシステムの地域設定に従い、ヘルプは対応する README を開きます。

Windows セットアップは Inno Setup の OS 言語判定を使い、手動選択も可能です。更新時は前回のインストーラー言語を引き継ぎます。アプリの言語設定とは独立しており、アプリは初期状態で「システムに従う」を使い、更新時は保存済みの選択を保持します。

キャラクター欄で **Golden · Waves**（従来の金髪）と **Blue · Hime cut**（青髪の姫カット）を切り替えられます。青髪のキャラクターは凛とした表情に柔らかな微笑みを添えています。選択は保存され、再起動後も維持されます。切り替えてもイントロの進行と 4 つの外観設定を保持します。初期値に戻す操作もキャラクターは変更しません。従来の 4 枚は変更せず、青髪は新しい 2 枚から読み込み時に線画を生成します。

| 設定 | 初期値 | 範囲 |
| --- | --- | --- |
| 実際の不透明度 | 20% | 0–100% |
| 彩度 | 1.30 倍 | 0–2 倍 |
| コントラスト | 1.10 倍 | 0.5–2 倍 |
| 明るさ | 0.70 倍 | 0.2–1.5 倍 |

初期値に戻すボタンで 4 項目をリセットし、イントロ再生ボタンで最初から再生します。イントロ中は不透明度を一時的に上げますが、手動調整時は選んだ実際の値をすぐに適用します。設定変更、非表示、アプリ切り替えでイントロは再開しません。パネルを閉じても動作を続けます。

表示切り替えのショートカットは macOS で **Ctrl+Option+Command+G**、Windows で **Ctrl+Alt+G**（使用可能な場合）。終了はメニュー／トレイから行います。マウス操作は透過しますが、絵が文字に重なる場合があります。別アプリが前面にある場合、対象が閉じられた場合や最小化された場合は非表示・停止し、専用パネルの操作中は表示を維持します。描画は約 30 fps に制限し、OS のアニメーションを減らす設定では静止画になります。

アニメーションは外部 API や素材を利用せず、HTTP サーバーも起動しません。Windows は WebView2 の仮想ホストで同梱ファイルを読み込み、ページの外部リクエストを拒否します。WebView2 自体のランタイム更新は Microsoft が別途管理します。macOS のアクセシビリティや画面収録の権限は不要です。フルスクリーン、異なる DPI、実機の複数画面は追加検証が必要です。

## アンインストール

**macOS：**`python3 manage.py uninstall` または `卸载.command` を実行します。Codex とソースフォルダは残ります。手動の場合は太陽メニューから終了し、任意のログイン時起動を `launchctl bootout gui/$(id -u)/local.codex.aura` で解除して、次を削除します。

- `~/Applications/Codex Aura.app`（または手動で置いた場所）。
- `~/Library/LaunchAgents/local.codex.aura.plist`（存在する場合）。
- 設定や任意の診断ファイルを消すには `~/Library/Application Support/Codex Aura`。

**Windows：**トレイから終了し、「設定 → アプリ → インストールされているアプリ → Codex Aura → アンインストール」、またはスタートメニューの削除項目を使用します。アプリとログイン時起動を含むショートカットを削除し、設定・キャッシュも削除するか確認します。サイレント削除では設定を保持します。終了後に `%LOCALAPPDATA%\Codex Aura` を手動削除することもできます。他のアプリと共有する WebView2 Runtime は削除不要です。

## 開発と検証

```sh
# macOS と共通描画の回帰テスト。Node.js と Python 3 が必要。
./scripts/test.sh
# Windows の設定・ポリシーテスト。.NET SDK 10.0.401 が必要。複数 OS で実行可能。
dotnet run --project windows/CoreTests -c Release
```

Windows に .NET SDK 10.0.401 と Inno Setup 6.5+ を導入して実行します。

```powershell
./windows/build.ps1 -Installer
```

.NET ランタイムを含む x64 アプリと、`windows/installer-output/` のインストーラーを生成します。WebView2 SDK 1.0.4258.31 は `packages.lock.json` で固定しています。CI では macOS 回帰、Windows テスト、専用ウィンドウでのネイティブ描画、インストール・削除を検証し、Windows インストーラーのみ配布用成果物としてアップロードします。実際のバージョン、結果、未完了の手動確認は[検証記録](docs/verification.md)を参照してください。

`source/` が macOS ホスト、`windows/CodexAura/` が Windows ホスト、`web/` が共通アニメーションです。[仕様](specs/windows-x64.md)と [3 言語の紹介文](DESCRIPTION.md)も参照できます。

## ローカライズ開発

`web/locales.json` は両ホスト、ローカル管理スクリプト、Windows の独自セットアップメッセージで共用します。3 言語のキーを揃え、ローカルビルド後に `python3 tests/test-localization.py` で確認してください。Swift と .NET のテストは言語判定と設定移行を、Windows CI はネイティブの言語選択と 3 言語のインストールを検証します。公式の中国語・日本語リソースを `windows/installer-languages/` に固定して収録し、Inno Setup の追加言語ファイルの有無に依存しません。[サードパーティ通知](docs/third-party.md)を参照してください。[要件](specs/localization.md)も参照してください。
