# Codex Aura

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

macOS の Codex に、まばたきと髪の揺れを添えるアニメ調オーバーレイ。クリック透過、リアルタイムの色調整、起動時のイントロに対応。

Codex Aura は独立した非公式のコンパニオンアプリです。Codex 自体を変更しません。4 枚のオリジナルテクスチャを Canvas と WebGL でローカル描画するため、動画再生、API キー、ネットワーク接続は不要です。現在のメニューと操作パネルは中国語です。このリポジトリのドキュメントは英語・中国語・日本語で提供しています。

## 機能

- 前面の Codex ウィンドウ全体に透明なオーバーレイを重ね、マウス操作を下のウィンドウへ通します。
- 起動ごとに「線画からカラーへ」のイントロを一度再生し、その後はまばたきと髪の動きを続けます。メニューから再再生できます。
- 実際の不透明度、彩度、コントラスト、明るさをスライダーや数値入力で調整し、自動保存します。
- 別のアプリが前面にあるとき、対象ウィンドウが表示されていないとき、手動で非表示にしたときは、描画を停止して非表示になります。専用の操作パネルを使う間は表示を維持します。
- 描画を約 30 fps に制限します。macOS の「視差効果を減らす」が有効な場合は静止画を表示します。
- 任意のログイン時起動と、スクリプトまたは手動によるアンインストールに対応します。

## 動作条件と現在の状態

- ビルドの対象は macOS 12 以降です。すべての OS バージョンで確認したわけではありません。
- 対象アプリのバンドル ID は `com.openai.codex` である必要があります。表示名はバージョンによって異なる場合があります。別の ID のアプリには自動対応しません。
- ビルドには Xcode Command Line Tools と Swift 5.7 以降のコンパイラが必要です。`build.sh` は実行する Mac のアーキテクチャ向けにビルドします。ネイティブ動作は Apple シリコンで確認しており、Intel は未検証です。
- Python 3 は管理スクリプト用、Node.js は JavaScript テスト用です。ビルド済みアプリの実行には不要です。
- ローカルビルドは ad-hoc 署名で、Apple の公証は受けていません。ダウンロードしたビルドは Gatekeeper によりブロックされる場合があります。正式な署名・公証済みの公開リリースは、まだ提供していません。

## ビルドと起動

プロジェクトのルートでターミナルを開きます。

```sh
# Apple の開発ツールが未導入の場合に実行します。
xcode-select --install

./build.sh
open 'Codex Aura.app'
```

生成される `Codex Aura.app` は Git の管理対象外です。npm のインストールやローカル HTTP サーバーは不要です。ビルドしたアプリを Applications フォルダへドラッグして起動することもできます。

`~/Applications/Codex Aura.app` にインストールするには、次を実行します。

```sh
python3 manage.py install
```

`安装并启动.command` のダブルクリックでも実行できます。Finder 用スクリプトは `/usr/bin/python3` を使用し、上記のコマンドは PATH 上の `python3` を使用します。インストール時にログイン時起動が新たに有効になることはありません。スクリプトでインストールした後、有効にする場合は別途実行します。

```sh
python3 manage.py enable-login
```

対応する Finder 用スクリプトは `开启登录自启.command` です。スクリプトによる更新では、すでに有効にしたログイン時起動の設定を維持します。

## 操作

メニューバーの太陽アイコンから **调色控制面板…**（色調整パネル）を選択します。初回起動時は自動表示されます。スライダーを動かすか、数値を入力して Return を押す、または入力欄を離れると適用されます。

| 設定 | 初期値 | 範囲 |
| --- | --- | --- |
| 実際の不透明度 | 20% | 0–100% |
| 彩度 | 1.30 倍 | 0–2 倍 |
| コントラスト | 1.10 倍 | 0.5–2 倍 |
| 明るさ | 0.70 倍 | 0.2–1.5 倍 |

**恢复默认** で初期値に戻り、**重播开场** でイントロを再再生します。イントロ中は不透明度が一時的に上がりますが、外観設定を手動で変更すると、選択した実際の不透明度がすぐに適用されます。設定変更やアプリの切り替えでイントロは再開しません。パネルを閉じてもオーバーレイは動作を続けます。

**隐藏浮层 / 显示浮层** で非表示・表示を切り替えます。利用可能であれば **Control + Option + Command + G** も使えます。**退出曦光浮层** で終了します。

## 動作とプライバシー

アニメーションはアプリが前面にあるかどうかに従い、モデルの処理状態や実際の読み込み進捗は示しません。チャット内容は読み取りません。同じ対象アプリ内の別のページでも表示される場合があります。コンパニオンアプリにアクセシビリティや画面収録の権限は不要です。

マウス操作は透過しますが、表示が文字と重なることはあります。不透明度を調整してください。ネイティブのフルスクリーンや実機での複数ディスプレイ切り替えは、まだ十分に検証していません。キャラクターは 2.5D のテクスチャ変形で動き、完全な 3D モデルや Live2D モデルではありません。

## アンインストール

スクリプトでインストールした場合は、次を実行します。

```sh
python3 manage.py uninstall
```

`卸载.command` のダブルクリックでも実行できます。コンパニオンを停止し、インストール済みアプリ、ログイン時起動の設定、保存設定を削除します。Codex とソースコードのフォルダは残ります。

手動で削除する場合：

1. 太陽メニューで **退出曦光浮层** を選択します。
2. ログイン時起動を有効にした場合は `launchctl bootout gui/$(id -u)/local.codex.aura` を実行するか、以下の削除後にログアウトします。
3. `~/Library/LaunchAgents/local.codex.aura.plist` があれば削除します。
4. `~/Applications/Codex Aura.app` を削除します。手動で別の場所に配置した場合は、そのコピーも削除します。
5. `~/Library/Application Support/Codex Aura` を削除し、設定と任意の診断ファイルを消去します。

## 開発とテスト

```sh
./scripts/test.sh
```

アプリのビルド、Swift の外観設定・ウィンドウポリシーの検証、Node の描画・イントロの回帰テスト、一時ホームディレクトリ内での Python のインストール・削除テスト、署名検証を実行します。インストーラーのテストは、既存のインストールやログイン時起動を変更しません。各 macOS バージョンでの実際のウィンドウ操作の検証は別途必要です。

| パス | 内容 |
| --- | --- |
| `source/` | ネイティブウィンドウ、メニュー、色調整パネル、設定、WebKit ブリッジ |
| `web/` | Canvas/WebGL レンダラーとオリジナルテクスチャ |
| `build.sh` | ローカルビルドと ad-hoc 署名 |
| `manage.py`、`*.command` | インストール、任意のログイン時起動、削除 |
| `tests/`、`scripts/test.sh` | 自動テスト |
| `specs/repository.md` | 移植の範囲と受け入れ条件 |
| [DESCRIPTION.md](DESCRIPTION.md) | 3 言語の短いプロジェクト紹介 |
